# Ecommerce Sales Analysis

## Overview

This project analyzes a comprehensive ecommerce sales dataset containing **9,994 orders** with **$2.3M** in total sales, covering **2011 to 2014**. The goal is to uncover trends, profitability, and performance metrics across categories, regions, and time periods to support data-driven business decisions.

---

## Dataset

- **File:** `Ecommerce-Sales-Analysis.xlsx`
- **Total Sales:** `$2.3M`
- **Total Profit:** `$286K` (12.47% margin)
- **Top Category:** `Technology` ($145K profit)
- **Top State:** `California` ($457K sales)
- **Peak Months:** `November ($349K)`, `December ($332K)`
- **YoY Growth:** `20.6%` sales increase (2011–2014)

---

## Analysis Performed

- Aggregated `sales`, `profit`, and `quantity` by **category**, **state**, and **month**.
- Calculated **profit margins** and **year-over-year growth**.
- Visualized monthly sales trends and category-wise profit contributions using `Matplotlib`.
- Identified actionable insights:
  - Focus on high-profit categories like **Technology**.
  - Target high-sales regions such as **California**.
